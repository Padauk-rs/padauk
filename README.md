# Padauk Framework

<div align="center">


      Padauk Framework


Build native mobile apps with the safety and performance of Rust.

</div>


### 📖 Introduction

**Padauk** is a cross-platform UI framework that allows you to write your application logic and UI layout entirely in **Rust**, while rendering **truly native components** on the device.

Unlike web-based frameworks or game engines, Padauk maps high-level Rust structs directly to:

* **Android**: Jetpack Compose (Material 3)

* **iOS**: UIKit / SwiftUI (Planned)

It features a robust **Dual-Layer Architecture**:

1. **Core SDK**: A pre-compiled native library handling the rendering engine.

2. **User App**: Your Rust code, compiled dynamically and linked via a high-performance FFI bridge.

### ✨ Features

* **Rust-First API**: Declarative UI syntax similar to SwiftUI or Jetpack Compose, but in Rust.

* **Native Rendering**: No WebViews, no canvas drawing. Uses platform-native widgets for accessibility and performance.

* **Type-Safe Assets**: The CLI automatically scans your assets/ folder and generates strict Rust constants (e.g., assets::ICONS_HOME).

* **Zero-Boilerplate Entry**: A simple attribute macro #[padauk::main] handles the platform handshake for you.

* **Smart CLI**: `padauk run` auto-selects Android, iOS, and Chrome web targets and handles Rust compilation, binding generation, and platform builds. `padauk build android` produces APKs and `padauk build web` emits `web/app.wasm`.

### 🚧 Status

**Current State: Experimental / Pre-Alpha**

* ✅ **Android**: Fully functional. Supports Scaffolds, Lists, Text, Images, and basic State.

* ⚠️ **iOS**: Under active development (XCFramework generation and linking logic implemented).

* 🚧 **Web**: CLI template and Chrome run target are available (WASM/native HTML renderer scaffold).

### 🛠 Prerequisites

To develop with Padauk, you need:

1. **Rust Toolchain**: `rustup` installed.

2. **Android Development**:

   * Android Studio & SDK.

   * NDK (Side-by-side) installed via SDK Manager.

   * `rustup target add aarch64-linux-android` (and `x86_64` for emulators).

3. iOS Development (macOS only):

* Xcode.

* `rustup target add aarch64-apple-ios aarch64-apple-ios-sim`.

### 📦 Installation

Since Padauk is currently in active development, it is best to build the CLI from source:
```
# 1. Clone the repository
git clone https://github.com/aungthuya-dev/Padauk.git
cd padauk

# 2. Build the Framework Assets (AAR/XCFramework)
cd padauk
chmod +x script/build.sh
./script/build.sh

# 3. Install the CLI binary.
cd padauk-cli
chmod +x script/build.sh
./script/build.sh
cargo install --path . --features embed-assets
```

### 🚀 Getting Started

**1. Create a new project**
```
padauk create my_awesome_app
cd my_awesome_app
```

**2. Write your UI (`rust/src/lib.rs`)**
```
use padauk::prelude::*;

// Auto-generated assets module
mod assets; 

#[padauk::main]
fn main() -> impl Widget {
    scaffold(
        column(vec![
            image(assets::LOGO_PNG)
                .width(120.0)
                .height(120.0)
                .fit(BoxFit::Contain),
            
            text("Welcome to Padauk")
                .size(24.0)
                .padding(16.0),
                
            text("Build native, stay rusty.")
                .color("#666666")
        ])
        .align(MainAxisAlignment::Center)
    )
    .app_bar(app_bar("My App"))
}
```

**3. Run (auto-select)**

Padauk detects running Android emulators, booted iOS simulators, and a Chrome browser target for web projects.
```
padauk run
```
Run with release mode:
```
padauk run --release
```

**4. Build artifacts**

```
padauk build android
```

Release build (arm64-v8a by default):
```
padauk build android --release
```

Optional ABI override (comma-separated):
```
padauk build android --abi arm64-v8a,x86_64
```

Build web wasm bundle:
```
padauk build web
```

### 📂 Project Structure

A created Padauk project looks like this:
```
my_awesome_app/
├── assets/              # Place images/raw files here. CLI syncs them automatically.
│   ├── image/
│   └── raw/
├── android/             # Standard Gradle project (auto-managed).
├── ios/                 # Standard Xcode project (auto-managed).
├── web/                 # Web host files + generated app.wasm (Material template).
├── rust/                # Your native app Rust code lives here.
│   ├── Cargo.toml
│   └── src/
│       ├── lib.rs       # Entry point
│       └── assets.rs    # Auto-generated by CLI
└── padauk.toml          # Project configuration
```

./script/build.sh

./script/build.sh
